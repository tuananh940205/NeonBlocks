# Quality và portfolio

- Dùng Jobs/Burst chỉ khi có baseline và benchmark workload đủ lớn.
- Không bịa benchmark, profiler hay memory result.
- Evidence cuối dự án nằm trong `docs/profiling/`.
- Khi triển khai bài: chỉ đọc đúng heading Bài N; hoàn tất code, asset (nếu có), Unity setup, test và `docs/PROGRESS.md`; không làm nội dung bài tiếp theo.
- Nếu cần asset mới, tạo handoff cụ thể và placeholder; code nên hạn chế tối đa việc bài sau phải sửa lại bài trước mà vẫn giữ mạch logic.
- Tóm tắt các thay đổi liên quan trực tiếp đến trò chơi sau khi hoàn tất.
